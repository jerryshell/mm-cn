# Motorsport Manager 简体中文汉化补丁

把《Motorsport Manager》（Steam AppID 415200）的界面、剧情、新闻、教程等全部文本替换为简体中文，
并重建了游戏内的位图字体，使中文可以正常显示。

适用版本：Steam 正式版（buildid 2293100，64 位 `MM.exe`）。

补丁本体是 `resources.assets`（373 MiB，原文件 214 MiB），替换后游戏体积增加约 160 MiB。

---

## 一、安装

1. 关闭游戏。
2. 把整个补丁文件夹放到游戏的安装目录里（和 `MM.exe` 同级）：

   ```
   ...\Steam\steamapps\common\Motorsport Manager\
       ├─ MM.exe
       ├─ MM_Data\
       └─ 简体中文汉化\        ← 整个文件夹放这里
            ├─ 安装汉化.bat
            ├─ 卸载还原.bat
            ├─ resources.assets
            └─ 说明.md
   ```

3. 双击 `简体中文汉化\安装汉化.bat`。

脚本会自动找到游戏目录、把原文件备份成 `MM_Data\resources.assets.orig`，然后装上汉化。

> 补丁文件夹放别的地方也行：脚本会依次检查补丁文件夹附近、Steam 注册表里的安装路径、
> Steam 默认安装位置，都找不到时会提示手动输入 `Motorsport Manager` 文件夹的完整路径。

**不需要改语言设置。** 游戏是按 Steam 客户端语言去选文本列的（设置界面里的语言下拉框是空实现），
所以补丁把游戏读取的**全部 10 个语言列**（English / French / Italian / German / Spanish /
Brasilian / Dutch / Hungarian / Polish / Russian）都写成了简体中文。无论 Steam 客户端是中文、
英文还是其他语言，界面都会是简体中文。

## 二、卸载

- 双击 `卸载还原.bat`（用 `MM_Data\resources.assets.orig` 还原），或
- 用 Steam 的「验证游戏文件完整性」还原，或
- 手动把 `MM_Data\resources.assets.orig` 改名回 `resources.assets`。

如果备份文件已经存在，安装脚本不会覆盖它，所以反复运行安装脚本也不会把汉化文件误当成原版备份。
脚本还会检查当前文件的大小，发现是重复安装时会给出提示。

> Steam 的「验证游戏文件完整性」会把 `resources.assets` 还原成英文版，这属于正常现象，
> 重新运行一次 `安装汉化.bat` 即可。

### 字体

游戏的 UI 使用的是 TextMesh Pro 的**位图 SDF 字体图集**（例如 `CooperHewitt-Medium SDF Atlas`），
图集里只有拉丁字母，直接塞中文会显示成一堆空白方块。补丁做了两件事：

1. 把 11 个 UI 字体图集从 1024² / 2048² 扩展到 **4096²**，
   原图集内容**像素级保留**，空出来的区域用 **Noto Sans SC** 重新生成了 2,424 个
   中文（及全角标点）字形的 SDF 数据；
2. 同步更新了每个字体资产的字形表（位置、尺寸、基线偏移、步进宽度），
   中文的字号、字重与原来的英文字体观感一致。

用到的字重：Medium（正文）、Bold（标题）、Book/Regular（次级文字）、
Light / Thin（大字标题），分别对应游戏里不同的字体槽位。

生成流程按游戏原图集反推了 TMP 的 SDF 编码
（`alpha = 0.5 + distance_px / (2 × _GradientScale)`，`_GradientScale = padding + 1`），
并用同样的方式复算游戏自带的 550 个拉丁字形做校准：五个度量
（宽、高、左偏移、基线偏移、步进）与原图集的平均误差都在 **0.15 像素**以内。

### 标点与数字

中文文本使用全角标点；比赛计时、圈速、百分比仍按英文格式（`.` 作小数点），
因为游戏内部按语言枚举选择日期/数字格式，补丁沿用了英文格式以保证计时显示正确。

## 四、已知限制

- **真人语音没有替换。** 游戏里只有 19 段 `MM_RadioMessage_*` 语音音效，
  且无法可靠地把它们与具体台词一一对应；所有电台/语音对应的**字幕文本**已经汉化。
- **玩家输入的名字、车队名等仍按原样显示**，游戏自带的输入框不能输入中文
  （Unity 5.3 的 IME 限制），这是引擎层面的问题，与本补丁无关。
- 部分媒体新闻/推特是程序化拼接的句子，中文语序由机器翻译给出，
  个别长句读起来可能略生硬。
- 极少数（111 条，约 0.9%）句子里的变量（如 `{Player:Name}`）在中文里的位置
  与英文不同，这是按中文语法调整的结果，不影响功能。
