# 术语表与翻译原则

这份文档说明汉化里「为什么这么翻」，以及哪些词条故意保留了英文。
数据源是 [`tools/glossary.py`](../tools/glossary.py)，改术语请直接改那个文件。

---

## 一、通用原则

1. **优先用中文赛事圈的习惯说法**，不逐字直译。
   `Pit Stop` 是「进站」不是「维修停止」，`Podium` 是「领奖台」不是「讲台」。
2. **人名、车队名、赛事缩写保留原文。**
   `GMA`、`WMC`、`IGTC`、`IEC` 这些是游戏虚构的赛事名，用缩写比音译更好认；
   `Ernie Hecklerock` 这类人名也保持原文。
3. **数字、单位、计时格式跟随英文。**
   圈速仍是 `1:23.456`，百分比仍是 `30%`，小数点仍是 `.`。
   原因是游戏内部按语言枚举决定数字格式，沿用英文格式才能保证计时正确。
4. **标点用全角。** 逗号、句号、问号、冒号、引号一律全角，和中文正文一致。

## 五、故意保留英文的词条

`tools/glossary.py` 里的 `KEEP_LATIN` 列出了 61 条有意不翻译的文本。
它们要么没有可翻译的内容，要么翻了反而不好认：

| 类别 | 例子 | 原因 |
| --- | --- | --- |
| 字母键位 | `A` `B` `C` … `Z` | 就是按键本身 |
| 功能键 | `F1` … `F12` | 同上 |
| 数字小键盘 | `Numpad 0` 等（已翻译为「小键盘 0」）| 部分已翻译 |
| 缩写 | `GMA` `WMC` `APS` `IGTC` `GTCS` `IEC` `IEC-B` | 游戏虚构赛事名 |
| 品牌 | `Facebook` `Twitter` `ECU` | 专有名词 |
| 格式串 | `DD/MM/YYYY`、`MM/DD/YYYY` | 是格式模板，不是文字 |
| 纯占位符 | `{Player:FirstName},`、`{Subject:Name}（{Subject:Job}）` | 只有变量，没有文字 |
| 单位/符号 | `&`、`{Number} PSI`、`{Feet}'{Inches}''` | 空格和符号 |

`tools/accept.py` 会用这份清单判断「这一条没翻成中文是不是正常的」，
所以新增保留项必须同步加进 `KEEP_LATIN`，否则验收会报错。

## 六、怎么改术语

1. 打开 [`tools/glossary.py`](../tools/glossary.py)；
2. **整句**问题加进 `EXACT`（键是英文原文，值是想用的中文）；
   注意键必须是 CSV 里 `English` 列的**完整原文**，包含标点和变量；
3. **通用错词**加进 `FIXES`，三元组 `(匹配, 替换, 是否正则)`；
   顺序有意义 —— 长的规则写在前面，否则会被短的先吃掉
   （例如 `赛车技师` 必须排在 `技师` 之前）；
4. 改完重跑：

   ```bash
   python tools/build_patch.py --text-only   # 约 30 秒，不用重算字体
   python tools/verify.py
   ```

想验证某一条具体翻成了什么，可以临时用一行 Python 查缓存：

```bash
python -c "
import sys; sys.path.insert(0,'tools')
import glossary
from translate import load_cache, ckey
c = load_cache()
en = 'Design Facility'
print(glossary.lookup(en) or glossary.apply_fixes(c.get(ckey(en)) or ''))
"
```
